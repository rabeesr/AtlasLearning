# calculus-robotics — flashcards

20 active-recall cards covering: derivatives (limit definition, finite
differences), gradients, multivariable chain rule (manipulator Jacobian),
partials & mixed partials (Clairaut), Taylor expansion (linearization, small-
angle), line integrals (work), 1st-order ODEs (motor model), 2nd-order ODEs
(mass-spring-damper, damping regimes, state-space), numerical integration
(Euler, RK4), Lagrangian mechanics (Euler-Lagrange for the pendulum),
Laplace transform basics + transfer functions, and a PI controller.

Authored per `.claude/skills/generate-flashcards/SKILL.md`. Every front is a
recall PROMPT; every back ends with a "why it matters" tie-back.
