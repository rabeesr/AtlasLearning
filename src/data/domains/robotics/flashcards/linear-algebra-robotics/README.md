# linear-algebra-robotics — flashcards

20 active-recall cards covering: rotation matrices in $\mathrm{SO}(3)$, dot
product (projections), cross product (torque, frame construction), rank /
null space (singularities, redundancy), least squares (normal equations, QR),
eigenvalues (rotation axis, stability), SVD (pseudo-inverse, conditioning),
homogeneous transforms in $\mathrm{SE}(3)$, and positive-definite inertia.

Authored per `.claude/skills/generate-flashcards/SKILL.md`:
- every front is a recall PROMPT, never a definition lookup
- robotics framing (LiDAR, IMU, wrist torque, manipulator Jacobian) wherever natural
- each back ends with a "why it matters" tie-back to a robotics use case
- KaTeX via `$...$` / `$$...$$`
